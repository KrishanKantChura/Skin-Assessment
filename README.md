# Skin Assessment — Phase 2

An interactive, self-contained skin assessment web app that collects basic user details, skin type, skin concerns, location, and mobile number, then generates personalised product recommendations with pricing, cart functionality, checkout, sharing, and consultation CTAs.

## Run locally

Open `index.html` in a modern web browser.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and open the generated GitHub Pages URL.

## Note

This is a front-end/demo implementation. Product ordering, notifications, and some location behaviour are simulated in the browser and are not connected to a live backend.
